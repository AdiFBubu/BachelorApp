## Dataset Sample / Exemplu de Date

Pentru a ilustra structura datelor folosite la antrenarea rețelelor, mai jos este prezentat un eșantion dintr-o secvență video etichetată. 

### Secvență: Fericire (Happiness)
Secvența este compusă din **10 cadre (frames)** extrase dintr-un clip video, capturând evoluția dinamică a expresiei faciale:
* **Cadrul 1:** Stare neutră (*Neutral state*)
* **Cadrele 2-9:** Debutul și progresia mișcării musculare (*Onset*)
* **Cadrul 10:** Punctul de intensitate maximă a emoției (*Apex*)

### Detalii Tehnice ale Eșantionului
* **Clasă / Etichetă:** `happiness` (Fericire)
* **Lungime secvență:** 10 cadre (eșantionate uniform între declanșare și apex)
* **Rezoluție cadre:** 640x490 pixeli
